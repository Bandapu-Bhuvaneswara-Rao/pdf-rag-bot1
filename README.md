# PDF RAG Bot

A Retrieval-Augmented Generation (RAG) application that allows users to upload PDF documents and ask questions based on their content. The application uses semantic search and a Large Language Model (LLM) to generate accurate answers from the uploaded PDF.

## Features

- Upload PDF documents
- Extract and process PDF content
- Generate embeddings for semantic search
- Store embeddings using FAISS Vector Database
- Ask questions about uploaded PDFs
- AI-powered responses using Groq LLM
- Modern React-based user interface

## Tech Stack

### Frontend
- React.js
- Axios
- CSS

### Backend
- FastAPI
- LangChain
- FAISS
- HuggingFace Embeddings
- Groq API
- PyPDF
